ADAPTIVE LESSON

Making decisions with if statements

Programs become useful when they can make decisions. Python uses if, elif and else to control which instructions run.

💡

Think of it like a question

An if statement asks a question. If the answer is true, Python runs the indented block underneath it.

Basic structure 

age = 18

if age >= 18:
    print("You can vote")
else:
    print("You cannot vote")
1. Condition

Python evaluates age >= 18.

2. True branch

The first block runs when the condition is true.

3. Else branch

The second block runs otherwise.

QUICK CHECK

What will this print?

    result = "A"
else:
    result = "B"
